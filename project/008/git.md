## Команды

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY

git branch <Название ветки>  //Создать ветку

git checkout <Название ветки> //Перейти на существующую ветку

git checkout -b <Название ветки>  //Создать ветку и переключиться на неё

git add * или git add "main.cpp"

git status

git commit -m "My commit"

git commit -a -m "My commit" //Добавить в индекс и создать коммит

git log //Посмотреть список коммитов

git push origin main //Отправить изменения на удалённый гит репозиторий

git pull //Загрузить состояние удалённого гит репозитория

git config --global user.name "login"

git config --global user.email "email"
