Сущность: Книги
    Атрибуты: book_id (PK, INT), title (VARCHAR), year (INT), price (DECIMAL), stock (INT)
    Связи: «имеет» → Авторы (M:N), 
    «издана» → Издательства (M:1)
    книга - заказ (m:1)

Сущность: Заказ
    Атрибуты: offer_id (PK, INT), status (VARCHAR), date (INT), offer_price (DECIMAL), address (VARCHAR)
    Связи: «содержит» → Книга (1:N), 
    «имеет» → статус (1:1) 

Сущность: Покупатель
    Атрибуты: customer_id (PK, INT), status_card (VARCHAR), birth_date (INT), FIO_name (VARCHAR)
    Связи: «формирует» → Заказ (1:N), 
    «имеет» → Пропуск (1:1)


Бизнес правила:
1. Одна и та же книга не может быть выдана дважды одновременно
2. Один заказ не может содержать несколько покупателей
3. Один покупатель не может прочитать больше 3 страниц книги за 1 день
4. Одна книга не может соджержать в себе 2 главных героя
5. Каждая книга содержит книжных червей
6. Каждая книга может быть возвращена со слезами читающего при доказательстве, что он испытал настоящие эмоции концовки
