Массив = набор элементов с однотипными значениями, хранящихся в памяти <b>последовательно</b>, в котором доступ к элементу осуществляется по его <b>индексу</b>, т.е. номеру элемента, за время, не зависящее от размера массива, т.е. количества элементов.

Массивы бывают <b>статическими и динамическими</b>

Формат статического массива:
```
тип имя_массива[размер];
```

Элементы массива можно проинициализировать сразу при объявлении таким образом:

```
тип имя_массива[] = {
    значение0, значение1 // и тд
}
```

При таком формате можно не указывать размер массива, ведь он определится автоматом по кол-ву значений.

Доступ к элементу массива осуществляется с помощью оператора [] по индексу:
```
имя_массива[индекс_элемента]
```

Для перебора элементов массивов и других подобных структур данных в языке C++ имеется специальная форма цикла for:

```
for (тип имя_управляющей_переменной : имя_массива) {
    команды;
}
```
Такая форма цикла for называется <b>range-based for</b>


Приведем программу, в которой массив из 10 элементов типа double сначала заполняются с клавиатуры, а после выполняется поиск самого большого элемента и его индекс, а так же сумма всех.
Далее массив сортируется пузырьков и выводится на экран(консоль), причем вывод на экран сделаем с помощью range-based for.

```cpp
    //ВВОД
    cout << "Введите элементы" << endl;
    for (size_t i=0; i != SIZE; ++i) {
        cout << "№ " << i << ": ";
        cin >> arr[i];
    }

    //Поиск наибольшего элемента, его индекса
    //и суммы элементов
    double max_element = arr[0];
    size_t index_of_max = 0;
    double sum_of_el = 0.0;
    for (size_t i=0; i != SIZE; ++i) {
        if (arr[i] > max_element) {
            max_element = arr[i];
            index_of_max = i;
        }
        sum_of_el += arr[i];
    }
    cout << "Наибольший элемент: " << max_element 
        << ", его индекс: " << index_of_max 
        << endl << "Сумма элементов: "
        << sum_of_el << endl;

    //Сортировка пузырьком
    for(size_t i = SIZE; i != 0; --i)
        for(size_t j = 0; j != i - 1; ++j)
            if(arr[j] > arr[j + 1])
                swap(arr[j], arr[j + 1]);

    //Вывод отсортированного массива на экран (консоль)
    cout << "Отсортированный массив: \n";
    for (double element : arr)
        cout << element << " ";
        cout << endl;
```

## Двемерный массив
это одномерный массив одномерных массивов одного типа и размера. Такой массим можно представлять себе как таблицу или матрицу. 
Элементы в памяти хрянятся <b>последовательно</b>, так что на самом деле использование двумерных массивов необязательно: любая задача с ними решается и с помощью одномерных массивов. 

Формат объявления двумерного:
```
тип имя[количество_строк] [количество столбцов];
```
Заполним целочисленную матрицу 3х3 с клавиатуры, найдем ее определитель, сумму элементов последней строки. транспонируем матрицу и выведем резвультат на экран. 

```cpp
    const size_t ROWS = 3, COLS = 3;
    int matr[ROWS][COLS];
    //ввод
    for(size_t i = 0; i != ROWS; ++i)
        for(size_t j = 0; j != COLS; ++j){
            cout << "Элемент " << "," << j << ": ";
            cin >> matr[i][j];
        }

    //вычисление суммы элементов последней строки
    int sum = 0;
    for(size_t j = 0; j != COLS; ++j)
    sum += matr[2][j];
    cout << "Сумма элементов последней строки: " << sum << endl;

    //вычисление определителя
    int det = matr[0][0] * matr[1][1] * matr[2][2]
        + matr[0][1] * matr[1][2] * matr[2][2]
        + matr[1][0] * matr[2][1] * matr[0][2]
        - matr[2][0] * matr[1][1] * matr[0][2]
        - matr[2][1] * matr[1][2] * matr[0][0]
        - matr[1][0] * matr[0][1] * matr[2][2];
        cout << "Определитель: " << det << endl;

    // Транспонирование
    for(size_t i = 0; i != ROWS; ++i)
        for(size_t j = 0; j != i; ++j)
            swap(matr[i][j], matr[j][i]);

    // Вывод транспонированной матрицы
    for(size_t i = 0; i != ROWS; ++i)
        for(size_t j = 0; j != COLS; ++j){
            cout << matr[i][j];
            if(j != 2)
                cout << "\t";
            else
                cout << endl;
    }
```
